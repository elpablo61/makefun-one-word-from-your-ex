Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

The program writes exactly one word to `/output/entry.txt`: the word my ex
would use to describe me.

## The word

**almost**

She never said I was bad. She said I was almost. Almost enough, almost
ready, almost the one. One word, six letters, no explanation needed — and
no near synonym keeps the edge.

## How it was chosen

Five candidate words were written first — `unavailable`, `temporary`,
`exhausting`, `almost`, `placeholder` — then judged pairwise, twice per
pair with positions swapped, on the judge's own rubric: funny, painfully
honest, fresh, lands instantly. `almost` won every pairing: it is the
sharpest turn (a verdict, not a complaint), it stings because it is true,
and it is the smallest text in the field, which the tie-break rewards.

## Run

```sh
node main.ts
cat /output/entry.txt
```
